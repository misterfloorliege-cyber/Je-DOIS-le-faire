# Je DOIS le faire

SaaS moderne de gestion du temps, des tâches et des priorités — pour la vie professionnelle comme personnelle.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase Auth / Database
- Lucide React

## Démarrage

```bash
npm install
npm run dev
```

Copiez `.env.example` vers `.env` et renseignez les clés Supabase pour activer l'authentification et la synchronisation Google Calendar.
